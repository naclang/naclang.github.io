Documentation.

NaC sits between JavaScript and Python: braces for blocks, but no semicolons, and Python-style and, or, not, for x in list and elif.

greet.nacNaC
fn greet(name) {
    return `Hello, ${name}!`
}

people = ["Ada", "Turing", { name: "Grace" }]
for p in people {
    if type(p) == "map" { print(greet(p.name)) } else { print(greet(p)) }
}

Running and building

terminalbash
./nac app.nac                    # run a script
./nac build app.nac              # writes ./app
./nac build app.nac -o my_api    # custom name

nac build bundles the script and the runtime into one executable. It needs a C compiler and the src/ directory next to nac. Build steps are in the install guide.
