Language basics.

Comments and statements

comments.nacNaC
// single-line comment
/* block comment,
   can span lines */

x = 1        // no semicolon needed
y = 2; z = 3 // ';' is only a separator for several statements on one line

A ( or [ at the start of a new line is never glued to the previous line.

Keywords

Group Keywords
Functions fn, return
Control if, elif, else, for, in, while, break, continue
Logic and, or, not
Output print
Errors try, catch, throw
Web route
Literals true, false, null

Everything else (input, len, range, serve, json, ...) is a normal builtin function, so it never clashes with your variable names.

Data types

Type Example
int 42, -7
float 3.14
bool true, false
null null
string "hello" (escapes \n \t \\ \"), `Hi ${name}`
array [1, 2, 3], [], array(5) (5 zeros)
map { name: "Ada", "age": 36 }, {}, map()
function fn(a, b) { return a + b }, or the bare name of a declared function

type(x) returns "int", "float", "bool", "null", "string", "array", "map" or "function". Strings are limited to 8192 characters, arrays to 10,000 elements.

Template strings (interpolation)

Backtick strings embed any expression with ${ } (like JavaScript). Plain "..." strings never interpolate, so braces in JSON text are safe.

templates.nacNaC
name = "Ada"
print(`Hello ${name}! ${age + 1} next year, ${user.tags[0]}, ${len(items)} items`)

html(`<h1>${title}</h1>
<p>${count > 1 and "many" or "one"}</p>`)   // may span several lines

Templates can span lines and nest. The result is limited to 8192 characters, like any string.

Variables

Assignment is declaration, with no let or var:

variables.nacNaC
x = 5
x += 1          // also -= *= /=
x++             // x--

Inside a function, assigning to a name that already exists (local, then global) updates it; otherwise a new local is created. Parameters are always new locals. Reading an undefined variable, an out-of-range index or a missing map key gives null (undefined variable and bad index also print an error).

Operators

Operator Meaning
or and Logical, short-circuiting; return an operand (x = a or "default").
not Negation (also !). && || ! are accepted too.
== != < > <= >= Comparison. No chaining: write a < b and b < c.
in not in Membership: 2 in [1, 2], "k" in map, "ab" in "cab".
+ - + concatenates when either side is a string.
* / % Multiply, divide, modulo.
-x Unary minus.

Use pow(a, b) instead of **. There are no bitwise operators and no ternary.
