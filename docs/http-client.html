HTTP client and JSON.

client.nacNaC
res = http.get { url: "https://api.example.com/users/1" }
print(res.status, res.ok, res.data.name)

res = http.post {
    url: "https://api.example.com/users",
    body: { name: "Ada" },                  // map/array -> sent as JSON; string -> sent as-is
    headers: { "Authorization": "Bearer abc" },
    timeout: 10                             // seconds, default 30
}

http.get {
    url: "https://api.example.com/users",
    callback: fn(r) { print(len(r.data), "users") }
}

jsonParse(text)   jsonStringify(value)

http.<method> { options }: <method> is get, post, put, patch or delete; the options map must follow the method on the same line. Options:

Key Meaning
url Required, http:// or https://.
body String (sent as-is) or map/array (sent as JSON); not allowed for get.
headers Map of header name to value (Content-Type: application/json is added when there is a body, unless you set it).
timeout Seconds, default 30.
callback Function called with the response when it arrives.

The response

The response is a map, so it can be assigned to a variable:

Field Meaning
status HTTP status code, 0 if no response was received.
ok true for 2xx.
body Response text (limited to 8192 characters).
data The body parsed as JSON when it is JSON, otherwise null.
error null, or a message when the request itself failed (no connection, timeout, ...).

HTTP 4xx/5xx and network failures do not stop the script: check res.ok (and res.error).

A callback runs once the response is in, before the expression finishes (the call still blocks). The response is also the value of the expression. A callback can be an inline fn(r) { ... } or the name of a declared function.
