Control flow and errors.

if / elif / else

Parentheses around the condition are optional:

if.nacNaC
if x < 0 {
    print("negative")
} elif x == 0 {
    print("zero")
} else {
    print("positive")
}

else if works too.

Loops

loops.nacNaC
for item in [10, 20, 30] { print(item) }    // arrays
for key in person { print(key) }            // maps iterate their keys
for ch in "abc" { print(ch) }               // string characters
for i in range(5) { }                       // 0..4  (range(a, b) -> a..b-1)

while x > 0 { x-- }

Errors: try / catch / throw

errors.nacNaC
try {
    data = jsonParse(text)          // any runtime error inside the block ...
    print(data.name)
} catch e {                         // ... jumps here; `e` is the message (a string)
    print("bad input:", e)
}
  • catch e, catch (e) and a bare catch { } are all accepted.
  • Catches runtime errors such as invalid JSON, division by zero, bad indexes, undefined names, wrong argument counts and bad http.<method> options. Syntax errors are never caught.
  • After an error the rest of the try block is skipped, including in loops and in functions called from the block. try blocks can be nested and work with return, break and continue.
  • throw value raises your own error; e receives the value rendered as text. A throw outside any try stops the program with Uncaught: ....
  • A failed HTTP request is not an error: it comes back as res.ok == false with res.error set (see HTTP client).
