Build NaC from source.

NaC is a C program. You need a C compiler; on Unix you also need libcurl and OpenSSL's libcrypto. The Windows build uses WinHTTP and CNG, so no extra libraries are required.

Prerequisites

Platform Required
Linux GCC, libcurl headers, OpenSSL headers, pkg-config
macOS Clang or GCC, curl, OpenSSL 3, pkg-config (all from Homebrew)
Windows MSVC Build Tools or MinGW GCC

Install the Unix dependencies with your package manager:

packages shell 
# Ubuntu / Debian
sudo apt install build-essential libcurl4-openssl-dev libssl-dev pkg-config

# Fedora
sudo dnf install gcc libcurl-devel openssl-devel pkg-config

# Arch
sudo pacman -Syu base-devel curl-compat openssl pkg-config

# macOS (Homebrew's OpenSSL is keg-only)
brew install curl pkg-config openssl@3
export PKG_CONFIG_PATH="$(brew --prefix openssl@3)/lib/pkgconfig:$PKG_CONFIG_PATH"
Windows build.bat looks for cl.exe first and falls back to gcc. Install Visual Studio Build Tools with the Desktop development with C++ workload, or install MinGW and make sure gcc is on PATH.

Clone the repository

terminal git 
git clone https://github.com/naclang/nac.git
cd nac

Build the interpreter

Unix

terminal bash 
chmod +x build.sh
./build.sh

The build writes ./nac. It links libcurl and libcrypto; when pkg-config is available, the OpenSSL paths are read from it.

Windows

terminal cmd 
build.bat

The build writes nac.exe in the project root.

Verify the build

Run the language tour first. It needs no network and no server:

terminal NaC 
# Unix
./nac examples/lang/syntax.nac

# Windows
nac.exe examples\lang\syntax.nac

Then start a web example. The server blocks, so use a second terminal for the requests:

terminal two panes 
# pane 1
./nac examples/web/01_hello.nac

# pane 2
curl "http://localhost:8080/hello?name=Ada"
curl http://localhost:8080/users/1
Example notes 04_api_gateway.nac and 05_http_client.nac call public APIs and need internet access. 06_accounts.nac writes accounts_users.json into the working directory; delete that file to reset the demo.

Package a script

nac build embeds your script in a small C stub and compiles it with the same interpreter sources. The result runs on its own; no .nac file or NaC install is needed at runtime.

terminal bash 
./nac build app.nac                # writes ./app
./nac build app.nac -o my_api     # custom name
./my_api

This step still needs a C compiler and the src/ directory next to the nac executable. It is not a from-scratch compiler; it bundles the script with the runtime that was built with the interpreter.

Troubleshooting

curl/curl.h is missing

The libcurl development package is not installed. On Debian/Ubuntu that is libcurl4-openssl-dev; on Fedora it is libcurl-devel.

-lcrypto or openssl/evp.h is missing

Install libssl-dev (Debian/Ubuntu) or openssl-devel (Fedora). On macOS, install openssl@3 and set PKG_CONFIG_PATH as shown under Prerequisites.

cl.exe is not found on Windows

Install Visual Studio Build Tools with the C++ workload. If you prefer MinGW, install GCC and add it to PATH; build.bat will use it.

LNK1104: cannot open nac.exe

A NaC server is still running and holding the executable. Stop it, then run build.bat again.

Permission denied on Unix

Run chmod +x build.sh before starting the build.
