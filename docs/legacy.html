Removed syntax.

These forms are no longer supported. The old keywords and syntax fail at parse time; the removed functions are treated as unknown calls and fail at runtime. Use the replacements listed here.

Removed in v1.1 (old syntax)

Old Use instead
rn return
out(...) print
in(x) input()
: { } as else else / elif
C-style for (i = 0; ...; i++) for i in range(...) or while
http("GET", url) http.get { url: ... }
time() now()
serve(port, "handler") route
Mandatory ; Not needed

Removed: the old HTTP client functions

httpGet(url), httpPost(url, body), httpPut(url, body), httpPatch(url, body), httpDelete(url), httpRequest(method, url) and httpJson(method, url) are gone. Use http.get { url: ... }, http.post { url: ..., body: ... } etc. The parsed JSON that httpJson returned is res.data, the raw text is res.body.
