Input / output

io.nacNaC
print("a", 1, true)          // arguments joined by spaces; print() = empty line
name = input("Name? ")       // reads a line (string); null at end of input
n = int(input())             // convert explicitly

now()  sleep(ms)                // seconds since epoch; pause for milliseconds

Conversion and builtins

builtins.nacNaC
str(x) int(x) float(x) type(x) isNull(x)         // Python-style
toString toInt toFloat typeOf                     // camelCase aliases
urlEncode(s) urlDecode(s)
args()  env("NAME")  env("NAME", default)  exit(code)   // CLI tools, configuration
array(n)  map()  range(end)  range(start, end)
assert(condition)  assert(condition, message)
sqrt pow sin cos tan abs floor ceil round log exp
len upper lower trim replace substr indexOf contains split

array(n) creates an array of n zeros; map() creates an empty map. range(end) returns integers from 0 up to (but not including) end; range(start, end) starts at start. assert raises an error when its condition is false, optionally using the supplied message. Arrays are limited to 10,000 elements.

Time and dates

time.nacNaC
now()                                      // seconds since Unix epoch (int)
nowMs()                                    // milliseconds since Unix epoch (float)
formatTime(now())                          // ISO 8601 UTC text
formatTime(now(), "%F %T", "+03:00")       // fixed time-zone offset
parseTime("2024-11-14T16:00:00Z")          // timestamp in seconds, or null
parseTime("14/Nov/2024 04:00 PM", "%d/%b/%Y %I:%M %p")

formatTime(timestamp, format, zone) accepts a seconds-since-epoch timestamp, an optional C-style format (default ISO 8601), and an optional zone: "utc" (default), "local", or a fixed offset such as "+03:00". parseTime(text, format) accepts an optional format and returns null if the text cannot be parsed.

SQLite

SQLite functions are available in builds compiled with SQLite support. dbOpen returns a database handle, or null if opening fails.

database.nacNaC
db = dbOpen("app.db")              // use ":memory:" for a temporary database
dbExec(db, "CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, title TEXT)")
dbExec(db, "INSERT INTO notes (title) VALUES (?)", [title])
rows = dbQuery(db, "SELECT * FROM notes")            // array of row maps
note = dbGet(db, "SELECT * FROM notes WHERE id = ?", [id]) // first row or null
dbClose(db)

dbExec(db, sql, params) runs a statement and returns a map with changes and lastId; dbQuery returns all rows and dbGet returns the first row or null. Bind values using an array for ? placeholders or a map for named placeholders such as :title—do not concatenate values into SQL. Text, numbers, booleans and null can be bound. Use SQL statements for transactions (BEGIN, COMMIT, ROLLBACK).
