HTTP server.

server.nacNaC
static("public")                       // "/" -> public/index.html, /app.css -> public/app.css
static("/assets", "public/assets")     // mount a directory under a URL prefix

route GET "/hello/:name" {
    return html(`<h1>Hello, ${params.name}!</h1>`)
}

route POST "/api/users" {
    data = jsonParse(body)
    return json(data, 201)
}

serve(8080)                            // blocking

route METHOD "pattern" { ... }: METHOD is GET, POST, PUT, PATCH, DELETE, ... or * for any. Inside the body you have method, path, query, headers, body, params and cookie (see cookies).

  • :name captures a path segment into params.name (URL-decoded); a trailing * captures the rest into params["*"]. Routes are tried in declaration order.
  • At most 128 routes.

static(dir) / static(prefix, dir) serves GET/HEAD from a directory; directory URLs serve index.html; the MIME type comes from the extension; .. is rejected. Files can be up to 32 MB; up to 8 mounts.

Resolution order: routes, then static mounts, then 405 (the path matches a route for another method) or 404.

Responses

A route returns a string (200; text/html if it starts with <, else text/plain), a map with status, body and headers, or one of:

responses.nacNaC
html(body)        html(body, status)
json(value)       json(value, status)       // application/json
redirect(url)     redirect(url, status)     // 302 by default

Dynamic bodies and header values are limited to 8192 characters. Handlers run one at a time, so a slow route delays the others.
