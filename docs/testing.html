Testing and dev mode.

Tests are ordinary NaC scripts: declare routes, call them in-process and check the results.

assert

assert(condition, [message]) reports an error with the message (default Assertion failed) when the condition is false, and returns true otherwise.

In-process requests

request(method, path, [body, headers]) calls a route declared earlier in the script without opening a network port. The result is a map with status and body. Query strings are decoded, and header names are normalized, so read them in lowercase.

request_test.nacNaC
route GET "/hello/:name" {
    return json({ message: "Hello, " + params.name })
}

route POST "/echo" {
    return json({ body: body, contentType: headers["content-type"] })
}

response = request("GET", "/hello/Ada")
assert(response.status == 200, "route should return 200")
data = jsonParse(response.body)
assert(data.message == "Hello, Ada", "path parameter should reach route")

post = request("POST", "/echo", "payload", { "content-type": "text/plain" })
assert(jsonParse(post.body).contentType == "text/plain", "request header should reach route")

Commands

terminalbash
./nac test examples/lang/request_test.nac    # run a test script
./nac dev app.nac                            # restart when the script or .env changes

nac test also checks configuration defaults: examples/lang/config_test.nac asserts that env() returns its default when a variable is missing.
